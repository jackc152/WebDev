Web Technologies

HTML

HTML is short for HyperText MarkUp Language. HTML is basically pure text data that is "marked up" to then be rendered (put all together). HTML is NOT a programming language, it is a MARKUP language. It also holds elements / tags that are enclosed using ANGLE BRACKETS, not parenthesis or such like python. BRINGS THE ELEMENTS

CSS

CSS is short for Cascading Style Sheets. It is also a MarkUp language such as HTML, but what it does is it styles the web page, such as visual effects layouts and presentation effects. Its basically used to mainly STYLES THE ELEMENTS.

JavaScript

Javascript is a CODING/ PROGRAMMING language, NOT a MarkUp Language. JavaScript is used to MODIFY the behavior of the elements. It serves as the core structure of the web page, unlike HTML or CSS, JavaScript is what allows the user to interact with the web page and take in the user's inputs to then output a result.

Lua

Lua is a simple light weight programming language that means "moon" in in portuguese, it was first created in Brazil during 1993. Why use Lua? It is a simple and easy learning language derived off C++ (another advanced programming language). Where is this used? Its mainly used for game development engines, or medical uses like blood glucose monitoring. Some websites or apps like Roblox use the Lua engine, however uses a derivated version or their own version called LuaU, this makes Lua more portable, basically more flexible to the use.
